# 복습 알고리즘 근거

앱의 복습 방식은 두 가지다. 설정에서 고른다.

## 1. SM-2 간격 반복 (기본)
SuperMemo SM-2의 규칙을 알고있음/모름 2버튼에 맞춰 적용했다.

| 규칙 | 값 | 근거 |
|---|---|---|
| 첫 번째 복습 간격 | 1일 | SM-2 |
| 두 번째 복습 간격 | 6일 | SM-2 |
| 이후 간격 | 직전 간격 × EF (소수는 올림) | SM-2 공식 설명은 올림, Wikipedia 의사코드는 반올림이라 공식 설명을 따랐다 |
| EF 초깃값 / 하한 | 2.5 / 1.3 | SM-2 |
| 모름(실패) | 반복 횟수 0, 간격 1일로 초기화 | SM-2 실패 규칙 |
| 모름일 때 EF | −0.2 (하한 1.3) | Anki의 lapse 처리를 참고한 선택 (SM-2 원문은 grade로 EF를 갱신) |
| 알고있음일 때 EF | 유지 | SM-2 grade 4와 같음 (EF 변화량 0) |

- 모름으로 답한 카드는 `dueAt`을 현재 시각으로 둬서, 알고있음으로 답할 때까지 계속 복습 대상에 남는다 (Anki의 learning 단계와 비슷한 효과).
- 2버튼이라 SM-2의 0~5 grade 중 알고있음=4, 모름=실패로 단순화했다. **이는 이 앱의 설계 선택이며 원문 알고리즘과 다르다.**
- "모름일 때 EF −0.2"는 Anki의 lapse 처리를 참고했다고만 기억에 근거해 적었고, 조사 중 해당 수치를 직접 확인하지는 못했다. 미검증.

## 2. 모름만 반복
- 알고있음으로 답한 카드는 현재 라운드에서 제외한다.
- 모름 카드만 남아 반복하다가 전부 알고있음이 되면 라운드를 초기화하고 처음부터 다시 시작한다.
- 누적 알고있음/모름 횟수는 라운드와 상관없이 계속 쌓인다.
